# 目标

- LangGraph 重构与 Human-in-the-Loop（人工审批）

# 学习内容

- 创建 `AgentState` 保存共享状态
- 创建 `agent_node` 作为主节点，添加系统提示词，调用llm
- 创建 `should_continue` 作为判断节点，判断是否调用高危工具
- 创建 `checkpoint` 持久化节点，将对话保存到sqlite
- 用graph将各个节点和边连接起来，设置检查点为高危工具调用之前

# 踩坑

- 在持久化时节点挂起，但是没有进行处理，添加了新的问题，导致400报错

# 思考

- graph先设置好状态，然后定义节点，节点是一个函数，最后用边把节点连接起来，就成了一个有向图
- 可以在节点执行之前添加一个检查点，实现人工审批的功能
- graph自带各种持久化的库，可以方便地实现持久化
