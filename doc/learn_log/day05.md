# 目标

- 实现一个agentic-rag，将rag封装为工具，让agent自己决定是否调用，输入哪些参数
- 实现一个简单的记忆系统，将上下文保存到内存，多轮对话

# 学习内容

- 将rag封装为工具类`search_rag_tools`
- 注册工具
- 调用agent，测试检索效果
- 创建一个内存记忆库 `MEMORY_STORE`
- 通过 `session_id` 判断记忆库是否存在，不存在就创建新的
- 将对话记录提交到对应的`MEMORY_STORE[session_id]`中

# 踩坑

- 发现检索结果效果不是很好，初步判断为数据集问题，如果是清洗好的数据、结构化之后效果会更好
- 如果到了后期上下文就会非常长，就需要滑动窗口和对话摘要压缩

# 思考

- 普通rag是固定流程，每次调用。agentic-rag是让agent自己思考是否调用rag和参数
- 只是简单的agentic-rag，效果不是很好，还有很多可以优化的地方，检索前的数据优化和检索后的结果优化
- 通过设置`session_id`可以区分每个记忆库、区分对话，把不同的记忆拼接到上下文就可以实现简单的记忆系统，
