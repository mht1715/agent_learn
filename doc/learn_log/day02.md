# 目标

- 手搓 Function Calling 循环
- 先手写循环，看清“规划→调用→观察→再规划”到底发生在哪一行
- 把 loop 变成可观测、可兜底的运行时

# 学习内容

- 创建`builtin.py`工具，工具为普通函数+`@tool`注解
- 创建`registry.py`，统一注册和管理工具
- 创建`loop.py`，实现一个简单的loop，获取llm，绑定工具，最大循环5次，观察每次循环的消息和工具
- 使用`logging`日志，方便观察agent执行步骤以及后续结合`langfuse`，实现可观测性
- 设置同一工具+同一参数的可执行次数，超过就终止，防止agent反复调用
- 使用dict代替str返回结果，方便观察执行结果，例如：成功、终止、工具调用错误等
```json
{
  "status": "aborted",
  "reason": "max_steps",
  "answer": "达到最大步数 {MAX_STEPS}，任务未完成。",
  "steps": "MAX_STEPS"
}
```

# 思考

- 难度适中，创建工具并统一注册管理，在简单的loop循环中调用工具
- 学会了添加日志并观察，使用结构化返回结果，方便判断以及后续对结果进行处理，设置一些兜底条件，例如限制工具重复调用次数
